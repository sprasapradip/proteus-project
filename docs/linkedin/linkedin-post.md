I've been rebuilding my Proteus Projects repository, and it's now 15 projects you can open, simulate and learn from ⚡

It started in 2023 with my first circuits: a 5 V power supply, a rectifier, an op-amp LED flasher, an SCR latch, a 7-segment display and a scoring board. Since then it has grown into Arduino projects built around problems I see every day in Nepal:

🚦 a traffic light controller for a 4-way junction
💧 a water tank controller that protects the pump from running dry
🔥 a gas and smoke detector that closes the valve and sends an SMS
🌬️ a wind turbine controller and a wind vane that turns the turbine into the wind
🚗 smart parking, a railway level crossing and a vehicle speed detector (with a demo for Kathmandu, Pokhara, Chitwan and Hetauda)

Every Arduino project has its source code, a ready HEX file to load into Proteus, a wiring diagram and a README that explains why the circuit is built the way it is. Most of them also have an automatic simulator test, so you can see exactly what the firmware is supposed to do.

I'm sharing this mainly for engineering students. Reading about a circuit is one thing. Running it, breaking it and seeing what changes is how it actually clicks. Open a project, run it in Proteus, change a value and watch what happens.

👉 https://github.com/sprasapradip/proteus-project

If you're learning electronics or electrical engineering and something isn't clear, open an issue or message me. Feedback and ideas for the next projects are very welcome.
